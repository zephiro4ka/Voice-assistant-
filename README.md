# ASTRIX - Voice assistant

Голосовая помощница для Windows (по умолчанию её зовут Аня — имя можно поменять). Говоришь «Аня, открой Steam» — и она открывает. Работает прямо на компьютере: распознавание речи, голос и нейросеть
запускаются локально, без облака. Имя, внешний вид, блоки на экране — всё настраивается под себя.

> 🇷🇺 **Язык.** Пока программа сделана для русскоязычной аудитории: она понимает и говорит по-русски, интерфейс тоже
> на русском. В следующих обновлениях появятся и другие языки.
>
> 🇬🇧 **Language.** For now the app is made for a Russian-speaking audience: it understands and speaks Russian, and the
> interface is in Russian too. Other languages are coming in future updates.

## Что умеет

- **Голосом и текстом:** программы, сайты, окна, громкость, музыка, таймеры, счёт, погода, диктовка, поиск в интернете.
- **Нейросеть на компьютере** (llama.cpp): отвечает на вопросы, решает задачи, «смотрит» на экран.
- **Сценарии:** «Аня, уютный вечер» → открыть кино на втором мониторе, убавить звук… Можно собрать мышью во вкладке
  «Сценарии» или просто сказать: *«Аня, создай сценарий игровой вечер: запусти Steam и сделай громкость 40»*.
- **Подскажет, где настройка:** *«Аня, где поменять голос?»* — откроет настройки на нужном пункте и подсветит его оранжевым.
- **Процессы:** подробный диспетчер задач — куда уходит каждый гигабайт памяти, очистка ОЗУ, температуры, гибкие плитки.
- **Пульт в Telegram:** приложение в меню бота — настраиваемые быстрые команды, удалённый рабочий стол (поворот экрана, клавиатура,
  мышь, джойстик), быстрый запуск своих программ и сайтов. Нужен [cloudflared](https://github.com/cloudflare/cloudflared),
  вход только для владельца.
- **Статус в Discord:** «Слушает: трек — исполнитель», «Смотрит: видео».
- **Полная кастомизация:** своё имя помощницы (на него она отзывается и им подписывается везде), темы, обои,
  любой блок главного экрана можно перетащить и растянуть.

## Установка (готовая сборка)

1. Скачай `ASTRIX-Setup.exe` из [Releases](../../releases) и установи (всё нужное, включая нейросеть, он скачает сам) — или возьми архив `ASTRIX.zip` и распакуй в любую папку.
2. Запусти ASTRIX. При первом запуске она спросит, как её зовут, как зовут тебя и твой город.
3. Чтобы она отвечала нейросетью, положи модель `.gguf` в папку `models` рядом с `ASTRIX.exe`
   (или она сама найдёт модели LM Studio). Подойдёт, например, Qwen 3.5 4B в Q4_K_M; файл `mmproj-*.gguf`
   рядом с моделью даёт ей «глаза».

Если в сборке нет папки `models` (облегчённый архив), скачай отдельно и положи в `models`:

| Что | Файл | Откуда |
|---|---|---|
| Распознавание речи | `ggml-small.bin` | [whisper.cpp на Hugging Face](https://huggingface.co/ggerganov/whisper.cpp) |
| Живой голос Silero | `silero\v5_6_ru.pt` | [silero-models](https://github.com/snakers4/silero-models) (CC BY-NC-SA — только некоммерчески) |
| Запасной голос | `supertonic-3\…` | Supertonic 3 (ONNX) |

Без голосов Silero и Supertonic Аня говорит голосами Windows. Голосу Silero нужен Python с PyTorch
(`third_party\silero\venv`), см. `third_party\silero\silero_server.py`.

## Сборка из исходников

Нужна Visual Studio 2022+ с «Разработкой классических приложений на C++».

```bash
git clone <адрес этого репозитория>
```

Открой `ASTRIX.slnx`, выбери **Release x64** и собери, или:

```bash
powershell -ExecutionPolicy Bypass -File tools\make-release.ps1
```

Скрипт соберёт программу и положит готовую папку и архив в `dist\` — **без личных данных**.
`-WithModels` добавит голоса и распознавание речи из `models\`.

Движок нейросети — официальная сборка [llama.cpp](https://github.com/ggml-org/llama.cpp/releases) (win-vulkan-x64)
в `ASTRIX\third_party\llama.cpp`; ONNX Runtime — в `ASTRIX\third_party\onnxruntime`.

## Личные данные

Всё личное хранится только в `anya.ini`, `scenarios.json` и `pult.json` рядом с `ASTRIX.exe`: токен бота, твой ID в телеграме,
контакты, сценарии. Эти файлы в `.gitignore` и не попадают ни в репозиторий, ни в архив релиза.
Токен бота никому не показывай — с ним можно управлять твоим компьютером.

## Удаление

Настройки → «Полная кастомизация» → «Удалить программу». Удаляется папка программы со всеми данными и автозапуск
(перед этим она спросит подтверждение). Там же — «Настройки по умолчанию».
